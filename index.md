# Golf Performance Coach Privacy Policy

**Effective Date:** October 17, 2026

Golf Performance Coach is a personal fitness analytics application intended for use by its owner.

### Information Collected

With the user's authorization, the application accesses WHOOP data, including recovery scores, heart rate variability, resting heart rate, sleep information, physiological cycles, and workout activity.

### How Information Is Used

The information is used to display fitness trends, evaluate recovery, and support personal training and golf performance analysis.

### Storage and Security

Authorized WHOOP information is stored in a secured Supabase database. Access is restricted through authentication and appropriate access controls. WHOOP authentication tokens are stored securely.

### Data Sharing

WHOOP information is not sold or used for advertising. Data may be transmitted to an AI analysis service only when the user requests analysis, subject to the service's applicable privacy terms.

### Data Retention and Deletion

Data is retained while the application is in use. The user may revoke WHOOP authorization and delete stored information. Revoking authorization does not automatically delete previously stored records.

### Contact

For privacy questions or requests, contact the application owner using the contact information provided in the WHOOP developer application.
